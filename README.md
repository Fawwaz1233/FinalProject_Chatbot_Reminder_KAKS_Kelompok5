# Telegram AI Reminder Bot

A Telegram-based reminder bot that converts natural-language messages and class-schedule images into scheduled reminders.

The application uses Flask as the backend, Cohere AI for natural-language and image understanding, SQLite for reminder storage, and the Telegram Bot API for communication.

## Features

- Create reminders using natural language.
- Create reminders using relative time, such as `in 5 minutes` or `in 2 hours`.
- Create recurring weekly reminders, for example for a class schedule.
- Set reminders for a fixed duration, such as `for 6 months`.
- Upload a class-schedule image and automatically create weekly class reminders.
- Add notes to reminders, such as room information or medication instructions.
- List all reminders.
- Delete a specific reminder.
- Delete all reminders belonging to the current Telegram user.
- Generate friendly reminder messages using Cohere.
- Store reminders locally using SQLite.

## Workflow

### Text Reminder Workflow

1. The user sends a text message to the Telegram bot.
2. Telegram forwards the update to the Flask `/webhook` endpoint.
3. Flask identifies whether the message is a greeting, list command, delete command, update command, or a new reminder.
4. For a new reminder, Cohere extracts the task, frequency, start date, end date, time, and note.
5. Flask stores the reminder in SQLite.
6. The bot sends a confirmation message.
7. A background thread checks due reminders every 60 seconds.
8. When a reminder is due, the bot sends a Telegram notification.

### Schedule Image Workflow

1. The user uploads a timetable image to the Telegram bot.
2. Flask receives Telegram's `photo` payload.
3. Flask downloads the highest-resolution image using Telegram's `getFile` API.
4. The image is encoded as Base64.
5. Cohere Command A Vision extracts course names, weekdays, start times, and room information.
6. Flask creates weekly reminders for the extracted courses.
7. The bot returns a numbered list of created reminders.

## Technology Stack

| Component | Technology | Purpose |
|---|---|---|
| Messaging platform | Telegram Bot API | Receive messages and send notifications |
| Backend | Flask | Webhook server and reminder logic |
| AI for text | Cohere Command A Vision | Extract information from reminder messages |
| AI for images | Cohere Command A Vision with ClientV2 | Read class-schedule images |
| Database | SQLite | Store reminders locally |
| HTTP client | Requests | Communicate with Telegram API and download images |
| Date utility | python-dateutil | Calculate durations such as six months |
| Background processing | Python threading | Check reminders every minute |

## Prerequisites

Before running this project, prepare:

- Python 3.10 or newer.
- A Telegram Bot token from [BotFather](https://t.me/BotFather).
- A Cohere API key.
- ngrok, Cloudflare Tunnel, or another public HTTPS tunnel for local webhook development.

## Installation

### 1. Clone the Repository

```bash
git clone [https://github.com/Fawwaz1233/FinalProject_Chatbot_Reminder_KAKS_Kelompok5.git](https://github.com/Fawwaz1233/FinalProject_Chatbot_Reminder_KAKS_Kelompok5.git)
cd FinalProject_Chatbot_Reminder_KAKS_Kelompok5
```

### 2. Create and Activate a Virtual Environment

Windows:

```bash
python -m venv venv
venv\Scripts\activate
```

macOS/Linux:

```bash
python3 -m venv venv
source venv/bin/activate
```

### 3. Install Dependencies

```bash
pip install flask flask-cors cohere python-dateutil python-dotenv requests
```

### 4. Create a `.env` File

Create a file called `.env` in the project root directory:

```env
COHERE_API_KEY=your_cohere_api_key
TELEGRAM_BOT_TOKEN=your_telegram_bot_token
```

### 5. Start the Flask Server

```bash
python app.py
```

The local Flask server should run at:

```text
http://127.0.0.1:5000
```

### 6. Create a Public URL

For local development with ngrok:

```bash
ngrok http 5000
```

Copy the HTTPS URL generated by ngrok. For example:

```text
[https://example.ngrok-free.app](https://example.ngrok-free.app)
```

### 7. Register the Telegram Webhook

Open the following URL in a browser, then replace the placeholders with your actual token and public URL:

```text
[https://api.telegram.org/bot](https://api.telegram.org/bot)<TELEGRAM_BOT_TOKEN>/setWebhook?url=https://<YOUR_NGROK_URL>/webhook
```

Telegram should return a result similar to:

```json
{
  "ok": true,
  "result": true,
  "description": "Webhook was set"
}
```

## Reminder Data Model

The application stores data in `reminders.db`.

| Column | Description |
|---|---|
| `id` | Unique reminder ID |
| `task` | Main reminder activity |
| `frequency` | Reminder frequency, for example `weekly` |
| `start_date` | Next date on which the reminder will run |
| `end_date` | Final valid date for the reminder |
| `time` | Reminder time in `HH:MM` format |
| `user_number` | Telegram chat ID |
| `created_at` | Date when the reminder was created |
| `note` | Additional reminder details |

## Important Implementation Notes

- The reminder checker runs every 60 seconds.
- Weekly reminders move their `start_date` forward by seven days after being sent.
- Other recurring reminders move their `start_date` forward by one day.
- A reminder is deleted after it runs if its frequency is `once` or if its `start_date` and `end_date` are equal.
- Relative time such as `in 5 minutes` is calculated in Python rather than relying only on AI extraction.
- Timetable-image extraction depends on the clarity of the image and Cohere Vision accuracy.

## Troubleshooting

### Bot Does Not Respond

Check that:

- Flask is running.
- The public tunnel is running.
- The Telegram webhook URL ends with `/webhook`.
- `TELEGRAM_BOT_TOKEN` is valid.
- The Flask terminal does not show an error.

### Photo Cannot Be Read

Use a clearer screenshot or photo. Ensure that each course name, weekday, start time, and room information is visible.

Check the terminal for either:

```text
Cohere vision response:
```

or:

```text
Error extracting schedule from image:
```

### Reminder Is Not Sent

Check that:

- The Flask application is still running.
- Your computer or server remains active.
- The reminder time uses the `HH:MM` format.
- The current date is between `start_date` and `end_date`.
- The Telegram bot token is valid.
